部署步骤：

1. dotfiles 文件夹改名 ～/.config

2. brew install --cask font-jetbrains-mono-nerd-font

3. brew install jenv

4. curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash

5. brew install putty

6. brew install --cask wezterm

7. 打开wezterm

8. brew install android-platform-tools

9. brew install neovim


10. git clone https://github.com/jsjsjs333/nvim.git ~/.config/nvim
